# MD Studio Swift 전환 인수인계 문서

이 문서는 MD Studio를 Electron 앱에서 **맥 순수 앱(Swift)** 으로 다시 만드는 작업의 기준서입니다. 이 문서와 저장소의 코드만 보고 작업을 이어갈 수 있도록 썼습니다.

## 0. 진행 상황 (2026-10-26)

1~4단계를 모두 구현했습니다. 자동으로 확인한 것과 사용자가 직접 확인해야 하는 것을 나눠 적습니다.

| 단계 | 상태 | 확인 방법 |
|---|---|---|
| 1. 변환 엔진 | 완료 | `macos/MDCore` `swift test`: golden 168/168 일치 |
| 2. 기본 앱 | 구현·자동 점검 완료 | 자가 점검: 창, 편집기 서식·단축키, 미리보기 3종, 복사 4종(클립보드 한 항목에 HTML·텍스트·RTF), 열기·저장 |
| 3. 나머지 기능 | 구현·자동 점검 완료 | 자가 점검: 폴더 목록, 자동 저장, 안전한 쓰기, 임시본 복구, 외부 변경, 붙여넣기 변환, 보고서, PDF(A4), 메뉴, 설정, 끌어다 놓기 확인, Finder 열기 |
| 4. 마무리 | 완료 | 다크 모드 화면 사진 확인, 메모리 실측 45MB(`footprint`, 예제 문서 1개·분할 보기) |

**사용자가 직접 확인해야 하는 것** (자동 점검으로는 확인할 수 없음)
- Slack·Google Docs·Pages·메일에 실제로 붙여 넣은 모습 (8장 함정)
- 한글 입력기로 직접 타이핑하면서 목록 Enter 이어 쓰기
- Finder에서 .md 파일을 "다음으로 열기 → MD Studio"로 열기, 창에 끌어다 놓기
- ⌘F 찾기 막대를 실제 키보드로 열기 (자동 점검은 다른 앱이 앞에 있어 메뉴 연결과 명령 실행까지만 확인)
- 미리보기 디자인이 웹 버전과 비교해 90% 이상 비슷한지 (화면 사진: `macos/build/selftest/*.png`)

**Electron 버전과 의도적으로 다르게 한 것**: README의 "Swift 순수 앱" 절을 보세요. 변환 경계 사례 3개(이미지 설명글 서식, 링크 주소의 `&amp;`, 이름 엔티티)는 사용자 결정으로 Swift 동작을 유지합니다.

## 1. 왜 바꾸는가

지금 앱(Electron)은 동작은 완전하지만 Chromium 엔진을 통째로 넣어서 무겁습니다.

| 항목 | Electron 버전 (현재) | Swift 버전 목표 |
|---|---|---|
| 앱 크기 | 310MB (그중 엔진 289MB, 우리 코드 0.7MB) | 수 MB ~ 20MB |
| 메모리 | 일반적으로 150~300MB (실측 아님) | **문서 1개 열린 상태에서 60MB 이하** (실측으로 확인) |
| 기능 | 아래 3장 전체 | **전부 유지** |
| 화면 | 기준 | 미리보기 디자인 90% 이상 비슷하게 |

사용자의 핵심 요구는 두 가지입니다. 메모리를 많이 먹으면 안 되고, 지금 기능과 화면 수준을 유지해야 합니다.

## 2. 원칙

1. **브라우저 엔진 금지**: WKWebView, Electron, Chromium을 상주시키지 않습니다. 화면은 AppKit 기본 부품으로 그립니다.
   - 예외: HTML 보고서는 "문자열로 파일을 쓰는 것"이라 렌더링이 필요 없습니다.
   - 예외: 웹 서식 붙여넣기 변환에서 `NSAttributedString(html:)`이 내부적으로 WebKit을 잠깐 쓰는 것은 허용합니다. 메모리를 상주시키지 않는지 측정해서 확인해야 합니다.
2. **기존 Electron 버전은 지우지 않습니다.** Swift 버전은 `macos/` 폴더에 새로 만듭니다. 웹 버전 코드(`src/`)가 동작 명세의 원본입니다.
3. **변환 결과는 기존과 같아야 합니다.** `test/fixtures/golden.json`의 정답과 대조하는 테스트를 반드시 둡니다(6장).
4. **로그를 적극적으로 남깁니다.** 저장, 복사, 오류, 성능을 기록합니다. 문서 본문은 기록하지 않습니다(7장).
5. **사용자는 3개월 차 주니어 수준입니다.** 설명은 한국어로 쉽게 하고, 사용자가 할 일(빌드, 권한 허용 등)은 단계별로 안내합니다.

## 3. 기능 명세 (지금 버전 기준)

동작이 애매하면 괄호 안의 원본 코드를 보세요.

### 3.1 편집기 (`src/editor.js`)
- 마크다운 문법 색칠: 제목 크게·굵게, 굵게/기울임/취소선, 링크·URL 색, 인라인 코드 고정폭, 인용 흐리게, `#` `-` `**` 같은 기호는 흐린 색
- 서식 명령(도구 막대 버튼과 단축키)

| 명령 | 단축키 | 동작 |
|---|---|---|
| 굵게 / 기울임 / 취소선 / 인라인 코드 | ⌘B / ⌘I / ⌘⇧X / ⌘E | 선택 영역 감싸기, 이미 감싸져 있으면 해제. 선택이 없으면 자리표시 글자를 넣고 선택 |
| 링크 | ⌘K | `[텍스트](https://)`. 선택이 URL이면 텍스트 부분을, 아니면 URL 부분을 선택 |
| 제목 1~3 | ⌘⌥1~3 | 줄 앞에 `#` 붙이기·바꾸기·해제(토글) |
| 글머리 / 번호 / 할 일 / 인용 | ⌘⇧8 / ⌘⇧7 / - / - | 선택한 모든 줄에 적용, 전부 같은 형식이면 해제. 번호는 1., 2.… 순서대로 |
| 코드 블록 / 표 / 구분선 | - | 블록 삽입. 표는 3열 2행 틀 |

- 목록에서 Enter를 누르면 다음 항목 기호 자동 입력, Tab/⇧Tab으로 들여쓰기
- 찾기/바꾸기(⌘F), 실행 취소, 긴 줄 자동 줄바꿈(설정)
- 붙여넣기 변환(설정, 기본 켬, `src/output.js`의 `convertPaste`)
  - 클립보드의 텍스트가 이미 마크다운처럼 보이면 텍스트를 그대로 붙입니다. 판정: 줄 시작이 `#`, `-`, `1.`, `>`, ```` ``` ````, `|…|`이거나, `**굵게**` 또는 `[a](b)`가 있으면 마크다운으로 봅니다.
  - HTML에 서식 정보(h1~6, strong, b, em, ul, ol, table, a, code, pre, blockquote, img, `font-weight:700`)가 있으면 마크다운으로 변환합니다.
  - Google Docs 함정이 두 가지 있습니다. 문서 전체를 `<b id="docs-internal-guid…" style="font-weight:normal">`로 감싸므로 이 태그는 굵게 처리하면 안 됩니다. 그리고 굵게/기울임을 `<span style="font-weight:700">`, `font-style:italic`으로 표현합니다.
  - 그 외에는 일반 텍스트로 붙입니다.

### 3.2 미리보기 3종 (오른쪽 탭)
- **문서**: GFM 렌더링. 제목(h1·h2 아래 구분선), 목록, 할 일 체크박스, 표(테두리, 머리글 배경, 짝수 행 배경, 열 정렬), 코드 블록(배경·테두리), 인용(왼쪽 막대), 구분선, 링크. 디자인 기준은 `src/styles.css`의 `.md-body`입니다.
- **Slack 미리보기**: Slack 메시지처럼 아바타와 이름 옆에 Slack 복사 결과를 표시합니다(`.slack-mock`).
- **텍스트 미리보기**: 텍스트 복사 결과를 고정폭 글꼴로 표시합니다.
- 표 변환 방식 선택(제목형 / 한 줄형 / 고정폭 표)은 미리보기 위에 둡니다.
- 보기 모드는 편집만 / 분할 / 보기만(⌘\)이고, 분할일 때 스크롤을 맞춥니다(설정).

### 3.3 복사 4종 (`src/main.js`의 `copy`)
편집기에서 일부를 선택했으면 선택한 부분만 복사합니다.

| 버튼 | 클립보드에 넣는 것 |
|---|---|
| Slack 복사 | HTML = `toSlackHtml`, 텍스트 = `toPlainText` |
| 서식 복사 | HTML = 인라인 스타일 문서 HTML(`toRichCopyHtml`), 텍스트 = `toPlainText`. Swift에서는 **RTF도 함께** 넣으면 Pages·Word 호환이 좋아집니다 |
| 텍스트 복사 | 텍스트만 |
| MD 복사 | 마크다운 원문 |

- 서식 복사 HTML은 `<style>` 블록을 쓰면 안 됩니다. 붙여넣는 앱이 버립니다. 모든 스타일을 태그에 직접 넣고(`INLINE_STYLES`), 체크박스는 ☑/☐ 문자로 바꿉니다.
- 클립보드에는 HTML과 텍스트를 **한 항목에 함께** 넣어야 합니다(NSPasteboard에 `.html`과 `.string` 동시 기록).

### 3.4 변환 규칙 (`src/convert.js` — 가장 중요)
정확한 기대 결과는 `test/fixtures/golden.json`에 있습니다. 아래는 요약입니다.

**텍스트(plain)**
- 제목: 1·2단계는 `■ 제목`, 3단계 이상은 `□ 제목`
- 블록 사이는 빈 줄 하나. 단 제목 바로 다음은 줄바꿈 하나(빈 줄 없음)
- 목록 기호는 깊이별로 `•` `◦` `▪`, 깊이당 공백 3칸. 번호 목록은 시작 번호 유지. 할 일은 기호 대신 `☑`/`☐`
- 인라인: 굵게·기울임·취소선·코드는 글자만 남깁니다. 링크는 `텍스트 (주소)`이고, 텍스트와 주소가 같으면 주소만 씁니다. 이미지는 `[이미지: 설명]`
- 인용은 각 줄 앞에 `│ `, 구분선은 `─` 20개, 코드 블록은 원문 그대로
- HTML 엔티티(`&amp;` 등)는 문자로 풉니다. HTML 태그는 제거하되 `<br>`은 줄바꿈으로 바꿉니다.
- 위험한 링크(`javascript:`, `vbscript:`, `data:`)는 주소를 버리고 글자만 남깁니다.
- 마지막 처리: 줄 끝 공백 제거, 빈 줄 3개 이상은 2개로 줄이고, 끝에 줄바꿈 하나

**표 변환** (텍스트·Slack 공통)
- 공통: 빈 칸은 생략합니다. 머리글이 비면 `항목 N`으로 씁니다.
- 1열 표: 칸마다 불릿 하나
- 2열 표: `첫칸: 둘째칸` 한 줄. Slack에서는 첫 칸을 굵게
- 3열 이상
  - 제목형(기본): 첫 칸이 굵은 불릿이 되고, 나머지는 `머리글: 값` 하위 불릿이 됩니다. 첫 칸이 비면 `머리글 행번호`를 씁니다.
  - 한 줄형: `첫칸 — 머리글: 값 · 머리글: 값`
- 고정폭 표: 열 너비를 맞추고(한글·한자·전각·이모지는 2칸, 최소 3칸), 구분은 ` │ `와 `─┼─`를 씁니다. Slack에서는 `<pre>`로 감쌉니다.

**Slack HTML**
- 쓰는 태그는 b, i, s, code, pre, a, ul, ol, li, blockquote, p, br뿐입니다. Slack이 나머지를 버리기 때문입니다.
- 제목은 `<p><b>…</b></p>`, 표는 위 규칙의 `<ul>` 중첩
- 블록 사이에 `<p><br></p>`를 넣습니다. 넣지 않으면 Slack이 연속된 두 목록을 하나로 합칩니다. 제목 바로 다음에는 넣지 않습니다.
- 번호 목록은 시작 번호가 1이 아니면 `start` 속성을 넣습니다.
- 이미 엔티티로 쓰인 `&amp;`는 다시 이스케이프하지 않습니다.

**옵션**: `breaks`(기본 true)가 켜져 있으면 엔터 한 번을 줄바꿈으로 인식합니다. 텍스트에서는 `\n`, Slack에서는 `<br>`이 됩니다.

**결정이 필요한 기존 불일치**: 표 칸 안의 `<br>`은 텍스트 복사에서는 ` / `로, Slack 복사에서는 `<br>`로 바뀝니다(golden의 `표_셀_줄바꿈`). Swift 버전은 일단 golden대로 맞추고, 통일할지는 사용자에게 물어보세요.

### 3.5 파일과 폴더 (`src/storage.js`, `electron/main.cjs`)
- 폴더 열기: 하위 4단계까지 `.md .markdown .mdown .mkd .txt` 파일을 목록에 표시합니다. 숨김 파일과 `node_modules .git .obsidian .Trash`는 제외하고, 최대 2000개, 한글 이름 순으로 정렬합니다. 파일 수가 8개 이상이면 검색창을 보여 줍니다.
- 앱을 다시 켜면 지난 폴더와 지난 파일을 자동으로 엽니다.
- 저장(⌘S): 열린 파일에 덮어씁니다. 새 문서라면 첫 `#` 제목으로 파일 이름을 제안하고, 같은 이름이 있으면 `이름 2.md`처럼 번호를 붙입니다(덮어쓰기 금지).
- **안전한 쓰기**: 같은 폴더의 `.파일명.mdstudio-tmp`에 먼저 쓰고 rename합니다. 저장 중에 꺼져도 원본이 망가지지 않게 하기 위해서입니다.
- 다른 이름으로 저장(⌘⇧S), 열기(⌘O), 새 문서(⌘N)
- 자동 저장: 열린 파일이 있으면 마지막 입력 1.5초 뒤에 저장합니다(설정, 기본 켬).
- 임시본: 저장하지 않은 내용은 0.7초마다 따로 보관합니다.
  - 새 문서의 임시본은 다음 실행 때 묻지 않고 복구하고, 알림을 띄웁니다.
  - 파일의 임시본이 파일보다 최신이면 "복구할까요?"라고 묻습니다.
- 외부 변경 감지: 창이 다시 활성화될 때 파일의 수정 시각을 확인합니다.
  - 편집 중이 아니면 조용히 다시 불러오고 알림을 띄웁니다.
  - 편집 중이면 덮어쓰지 않고 경고만 합니다.
- 다른 문서로 넘어갈 때 저장하지 않은 내용이 있으면, 자동 저장이 켜진 경우 저장하고 넘어갑니다. 꺼져 있으면 "저장 / 저장 안 함 / 취소"를 묻습니다.
- 창을 닫거나 종료할 때도 저장하지 않은 내용이 있으면 확인합니다.
- .md 파일을 창에 끌어다 놓으면 열립니다. Finder의 "다음으로 열기"로도 열립니다(문서 타입 등록, `CFBundleDocumentTypes`의 md·markdown, 역할은 Editor, 순위는 Alternate).

### 3.6 내보내기 (`src/output.js`의 `buildReportHtml`)
- **HTML 보고서**
  - 제목: 첫 `#` 제목이 기본이고, 사용자가 고칠 수 있습니다.
  - 날짜는 `YYYY년 M월 D일` 형식으로 넣습니다(선택).
  - 소제목(h2·h3)이 3개 이상이면 목차를 넣습니다(선택).
  - 본문 첫 h1이 제목과 같으면 중복이므로 뺍니다.
  - 표는 가로 스크롤 영역으로 감쌉니다.
  - 꼬리말: `MD Studio에서 생성 · 날짜`
  - CSS는 `REPORT_CSS`를 **그대로 복사**합니다(인쇄용 규칙 포함).
- **PDF**: 인쇄 창 없이 PDF 파일로 바로 저장합니다(A4, 배경 포함).

### 3.7 메뉴 막대 (`electron/main.cjs`의 `buildMenu`)
- 앱: 정보, 설정(⌘,), 가리기, 종료
- 파일: 새 문서, 열기, 폴더 열기(⌘⇧O), 저장, 다른 이름으로 저장, HTML 보고서, PDF(⌘P), 창 닫기
- 편집: 기본 편집 항목 + Slack용으로 복사(⌘⇧C), 서식 포함 복사(⌘⌥⇧C), 텍스트로 복사(⌘⇧T), 마크다운 원문 복사
- 보기: 편집만, 편집+미리보기, 미리보기만, 보기 전환(⌘\), 파일 목록 보이기/숨기기, 확대·축소, 전체 화면
- 도움말: 사용법과 단축키(⌘/), 로그 보기, 로그 폴더 열기

### 3.8 설정 (기본값)
표 변환 방식(제목형), 엔터 한 번을 줄바꿈으로(켬), 붙여넣기 변환(켬), 자동 저장(켬), 스크롤 맞추기(켬), 긴 줄 자동 줄바꿈(켬), 편집기 글꼴(일반/고정폭, 일반), 글자 크기(15), 테마(시스템 따르기/밝게/어둡게)

### 3.9 첫 실행
예제 문서(`src/sample.js`)를 엽니다. 도움말 창에서 다시 불러올 수 있습니다.

## 4. 권장 구현 방법

| 영역 | 권장 | 이유 |
|---|---|---|
| 앱 골격 | AppKit + 필요한 곳만 SwiftUI, 최소 macOS 13 | 편집기 세부 제어는 AppKit이 필요함 |
| 마크다운 분석 | [swift-markdown](https://github.com/swiftlang/swift-markdown) (Apple, cmark-gfm 기반) | GFM 표·취소선·체크박스 지원. 정확한 태그/버전은 최신 릴리스를 확인하고 고정 |
| 편집기 | `NSTextView` + `NSTextStorage` 위에서 정규식·AST 기반 색칠 | 한글 입력, 찾기, 실행 취소, 맞춤법이 기본 제공 |
| 문서 미리보기 | AST → `NSAttributedString`. 표는 `NSTextTable`/`NSTextTableBlock`, 코드·인용 배경은 단락 블록 스타일 | 브라우저 엔진 없이 표 테두리와 배경 표현 가능 |
| 클립보드 | `NSPasteboard`에 html·string·rtf 동시 기록 | 붙여넣는 앱이 알맞은 형식 선택 |
| 붙여넣기 변환 | 클립보드 HTML → `NSAttributedString` → 속성을 마크다운으로 변환 | 3.1의 판정 규칙 유지 |
| PDF | 미리보기용 `NSAttributedString`을 `NSPrintOperation`으로 PDF 저장 | 인쇄 창 없이 파일로 저장 가능 |
| 파일 접근 | 개인 배포이므로 App Sandbox를 **끄고** 일반 파일 접근 사용 | 샌드박스를 켜면 지난 폴더 기억에 security-scoped bookmark가 필요해져 복잡해짐 |
| 설정·임시본 | `UserDefaults` + `~/Library/Application Support/MD Studio/drafts/` | 임시본은 파일로 보관해 크기 제한을 피함 |

**대안 (변환 엔진만 해당)**: `src/convert.js`는 DOM을 쓰지 않습니다. 그래서 JavaScriptCore(브라우저가 아닌 JS 실행기, 시스템 내장)로 그대로 돌릴 수도 있습니다. 결과가 100% 같다는 장점이 있지만, 미리보기를 그리려면 어차피 Swift에서 AST가 필요하므로 **Swift 이전을 기본으로** 합니다. 이전이 막히면 이 대안을 쓰세요.

## 6. 테스트

- **정답 대조**: `test/fixtures/golden.json`의 각 사례에 대해 아래 출력을 비교합니다.
  - `plain_title`, `plain_inline`, `plain_grid`: 표 변환 방식별 텍스트
  - `slack_title`, `slack_grid`: Slack HTML
  - `*_nobreaks`: breaks 옵션을 끈 결과
  - `title`: 첫 제목
- swift-markdown과 기존 파서(marked)의 해석이 드물게 다를 수 있습니다. 불일치가 나오면 임의로 정답을 고치지 말고 차이를 정리해 사용자에게 보고하세요.
- 변환 규칙을 바꾸면 웹 버전도 함께 고친 뒤 `node test/make-golden.mjs`로 정답을 다시 만듭니다.
- 기존 테스트는 `npm test`(변환 18개), `npm run e2e`(화면 19개), `npm run e2e:app`(Electron 앱 14개)입니다. 3장의 동작을 확인하는 시나리오로 참고하세요.

## 7. 로그

- 파일 위치: `~/Library/Logs/MD Studio/app.log`. 1MB가 넘으면 `.old`로 돌리고 새로 씁니다.
- 기록하는 것: 시작(버전, macOS), 폴더·파일 열기, 저장(파일 이름, 바이트), 복사(종류, 글자 수, 선택 여부), 내보내기, 외부 변경 감지, 모든 오류(원인 포함), 느린 렌더링(80ms 넘을 때)
- 기록하지 않는 것: **문서 본문**
- 앱 안의 로그 창에서 보기, 복사, 비우기가 가능해야 합니다. 도움말 메뉴에서 로그 폴더를 열 수 있어야 합니다.

## 8. 지금까지 겪은 함정

- **Slack 붙여넣기 간격**: 블록 사이 `<p><br></p>`가 없으면 목록끼리 합쳐집니다(3.4).
- **Google Docs HTML**: 전체 감싸기 `<b>`와 span 스타일(3.1)
- **Electron 44 클립보드 API 변경**: 예전 방식 `clipboard.write({html,text})`가 막혀서 복사가 전부 실패했었습니다. 시스템 API가 바뀔 수 있으니 복사 기능은 반드시 실제로 붙여서 확인하세요.
- **한글 파일 이름**: 리눅스 기본 로케일에서 깨진 적이 있습니다. 맥에서는 문제없지만, NFC/NFD 정규화 차이는 주의하세요. 맥 파일 시스템은 이름을 그대로 보존합니다. 목록 비교나 검색은 정규화한 값으로 하세요.
- **저장 중 종료**: 반드시 임시 파일에 쓴 뒤 rename합니다(3.5).
- **서명**: Apple Silicon은 서명 없는 실행 파일을 실행하지 않습니다. 개인용 빌드는 `codesign --force --deep --sign -`(자체 서명)이면 됩니다. Xcode의 "Sign to Run Locally"도 같은 효과입니다.
- **인터넷에서 받은 앱 경고**: 맥에서 직접 빌드한 앱에는 quarantine 꼬리표가 없어 경고가 뜨지 않습니다. 다른 맥으로 보내면 다시 뜹니다.
