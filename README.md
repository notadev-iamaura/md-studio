# MD Studio

내 맥에서 쓰는 마크다운 편집기, 뷰어, 변환기입니다. 파일 하나(`MD-Studio.html`)로 동작하고, 설치나 인터넷 연결이 필요 없습니다. 문서는 서버로 전송되지 않고 내 맥의 폴더에만 저장됩니다.

## 맥 앱으로 설치 (권장)

Chrome 없이 혼자 실행되는 맥 앱입니다. macOS 13(Ventura) 이상에서 동작합니다.

1. 내 맥에 맞는 파일을 고릅니다. 화면 왼쪽 위 Apple 메뉴 → "이 Mac에 관하여"에서 "칩" 항목을 확인하세요.
   - "Apple M1, M2, M3, M4…"로 나오면 `MD-Studio-1.0.0-mac-apple-silicon.zip`
   - "Intel"로 나오면 `MD-Studio-1.0.0-mac-intel.zip`
2. zip을 더블클릭해 압축을 풀고, `MD Studio.app`을 **응용 프로그램(Applications)** 폴더로 옮깁니다.
3. 처음 한 번은 맥이 실행을 막습니다. Apple 개발자 인증서(유료)로 서명하지 않은 앱이기 때문입니다. 다음 순서로 허용합니다.
   - `MD Studio`를 더블클릭하면 "열 수 없음" 창이 뜹니다. "완료"를 누릅니다.
   - **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래로 내리면 "MD Studio이(가) 차단되었습니다"가 보입니다. 옆의 **"그래도 열기"**를 누르고 맥 암호를 입력합니다.
   - 확인 창에서 "열기"를 누릅니다. 다음부터는 바로 열립니다.
4. Dock에 고정하려면, 앱이 켜진 상태에서 Dock의 MD Studio 아이콘을 우클릭한 뒤 "옵션 → Dock에 유지"를 고릅니다.

**앱에서만 되는 것**
- 파일은 맥의 디스크에 직접 저장합니다. 저장 중에 앱이 꺼져도 원본이 망가지지 않도록, 임시 파일에 먼저 쓴 뒤 바꿔치기합니다.
- 폴더와 파일은 맥 기본 선택 창으로 고릅니다. 앱을 다시 켜면 지난 폴더가 자동으로 열립니다.
- PDF로 내보내기는 인쇄 창 없이 바로 PDF 파일로 저장됩니다.
- 메뉴 막대를 지원합니다. 편집 메뉴에 "Slack용으로 복사"(⌘⇧C), "텍스트로 복사"(⌘⇧T)가 있습니다.
- Finder에서 .md 파일을 우클릭하고 "다음으로 열기 → MD Studio"를 고르면 바로 열립니다. 항상 MD Studio로 열려면, 파일을 우클릭해 "정보 가져오기" → "다음으로 열기"에서 MD Studio를 고르고 "모두 변경"을 누릅니다.
- 앱은 사용자가 직접 고른 폴더와 파일 안에서만 읽고 씁니다.
- 실행 기록은 `~/Library/Logs/MD Studio/main.log`에 남습니다. 메뉴 "도움말 → 로그 폴더 열기"로 바로 열 수 있습니다.

## HTML 파일로 바로 실행 (앱 없이)

1. `MD-Studio.html`을 원하는 곳에 둡니다. 예를 들면 `문서/Apps` 폴더입니다.
2. 파일을 **Chrome**(또는 Arc, Edge)으로 엽니다. 파일을 우클릭한 뒤 "다음으로 열기 → Google Chrome"을 고르면 됩니다.
3. 자주 쓴다면 Chrome 북마크바에 추가해 두세요.

Safari에서도 편집, 미리보기, 복사, 내보내기는 모두 동작합니다. 다만 Safari는 "폴더에 직접 저장" 기능을 지원하지 않아서, 저장할 때 다운로드 폴더로 내려받는 방식이 됩니다.

## 주요 기능

**편집**
- 마크다운 문법 강조 표시가 되는 편집기를 씁니다(Obsidian과 같은 CodeMirror 엔진).
- 서식 도구 막대와 단축키를 지원합니다. 제목, 굵게, 기울임, 취소선, 코드, 링크, 목록, 할 일, 인용, 코드 블록, 표, 구분선을 넣을 수 있습니다.
- 목록에서 Enter를 누르면 다음 항목 기호가 자동으로 붙고, Tab으로 들여씁니다.
- 찾기와 바꾸기(⌘F), 실행 취소(⌘Z)를 지원합니다.
- 웹페이지, Google Docs, Notion에서 복사한 서식 있는 내용을 붙여넣으면 마크다운으로 바꿔 넣습니다. 이미 마크다운인 텍스트(AI 답변 등)는 그대로 넣습니다.

**미리보기 (오른쪽 탭)**
- 문서: 서식이 적용된 모습입니다.
- Slack 미리보기: Slack 입력창에 붙였을 때의 예상 모습입니다.
- 텍스트 미리보기: 서식 없는 텍스트로 바꾼 결과입니다.

**복사 (위쪽 버튼)**

| 버튼 | 붙여넣을 곳 | 표 처리 |
|---|---|---|
| Slack 복사 | Slack, Teams 등 메신저 | 목록으로 풀어서 |
| 서식 복사 | Google Docs, Word, Gmail, Notion | 표 그대로 |
| 텍스트 복사 | 메모장, 문자 등 어디든 | 목록으로 풀어서 |
| MD 복사 | GitHub, 다른 마크다운 편집기 | 원문 |

- 편집기에서 일부를 선택한 채로 누르면 선택한 부분만 복사합니다.
- Slack 복사는 클립보드에 "서식 버전"과 "텍스트 버전"을 함께 넣습니다. Slack처럼 서식을 받는 곳에는 굵게, 링크, 목록이 살아서 들어가고, 서식을 못 받는 곳에는 깔끔한 텍스트가 들어갑니다.

**표 변환 방식** (미리보기 오른쪽 위, 또는 설정에서 선택)
- 제목형: 첫 열을 굵은 제목으로, 나머지 열은 "머리글: 값" 하위 항목으로 풉니다. 기본값입니다.
- 한 줄형: 한 행을 "제목 — 머리글: 값 · 머리글: 값" 한 줄로 만듭니다.
- 고정폭 표: 한글 폭을 계산해 열을 맞춘 텍스트 표로 만듭니다. Slack에서는 코드 블록으로 들어갑니다.
- 공통 규칙: 빈 칸은 생략하고, 2열 표는 "키: 값" 한 줄로 만듭니다.

**저장**
- 왼쪽의 "폴더 열기"로 내 맥의 폴더를 고르면, 그 안의 .md 파일 목록이 보이고 바로 열고 저장(⌘S)할 수 있습니다. 하위 폴더 4단계까지 표시합니다.
- 열린 파일은 고친 뒤 약 1.5초가 지나면 자동 저장됩니다. 설정에서 끌 수 있습니다.
- 작성 중인 내용은 브라우저에도 임시본으로 보관됩니다. 창이 갑자기 닫혀도 다시 열면 복구됩니다.
- 다른 앱(예: Claude, VS Code)에서 같은 파일을 고친 뒤 이 창으로 돌아오면 바뀐 내용을 다시 불러옵니다. 편집 중이었다면 덮어쓰지 않고 경고만 표시합니다.
- .md 파일을 창에 끌어다 놓아도 열립니다.
- 다음에 열 때 지난번 폴더를 기억합니다. Chrome 보안 정책상 "지난 폴더 다시 열기" 버튼을 한 번 눌러 권한을 허용해야 할 수 있습니다.

**내보내기**
- HTML 보고서: 제목, 날짜, 목차(소제목 3개 이상일 때)가 들어간 단독 HTML 파일입니다. 메일 첨부나 공유용으로 쓸 수 있습니다.
- PDF: 보고서 모양으로 인쇄 창을 엽니다. 인쇄 창에서 "PDF로 저장"을 고르면 됩니다.

**로그**
- 화면 오른쪽 아래 "로그"를 누르면 저장, 복사, 오류 기록을 볼 수 있습니다. 문서 본문은 기록하지 않고, 파일 이름과 글자 수 같은 정보만 남깁니다.
- 문제가 생기면 "로그 복사"로 내용을 전달해 주세요.

## 단축키

| 키 | 동작 | 키 | 동작 |
|---|---|---|---|
| ⌘S | 저장 | ⌘O | 열기 |
| ⌘⇧S | 다른 이름으로 저장 | ⌘\ | 편집/분할/보기 전환 |
| ⌘B | 굵게 | ⌘I | 기울임 |
| ⌘K | 링크 | ⌘E | 인라인 코드 |
| ⌘⌥1~3 | 제목 1~3 | ⌘⇧X | 취소선 |
| ⌘⇧8 | 글머리 목록 | ⌘⇧7 | 번호 목록 |
| ⌘F | 찾기/바꾸기 | ⌘/ | 도움말 |

## 검증 상태

자동 테스트 51개가 모두 통과했습니다.
- 변환 로직 18개
- 브라우저 화면 동작 19개 (Linux Chromium)
- 데스크톱 앱 14개: 실제 앱을 실행해 디스크의 한글 이름 폴더에 저장, 자동 저장, 외부 변경 감지, 클립보드, PDF, 메뉴, Finder 열기, 접근 제한, 닫기 확인, 재실행 시 폴더와 임시본 복구를 확인 (Linux에서 같은 코드로 실행)

맥 앱 파일은 구조(실행 파일 종류, 앱 정보, .md 연결, 포함 파일)와 자체 서명까지 확인했습니다. 다만 아래 항목은 개발 환경이 Linux라서 자동 검증하지 못했습니다. 맥에서 처음 쓸 때 확인해 주세요.

1. **맥에서 앱 실행.** "그래도 열기" 허용 과정, 맥 기본 선택 창, 메뉴 막대 표시를 확인해 주세요.
2. **Slack에 실제로 붙여넣은 결과.** 클립보드에 들어가는 내용(HTML과 텍스트)은 검증했습니다. 하지만 Slack이 그것을 어떻게 해석하는지는 Slack 앱에서만 확인할 수 있습니다. 특히 빈 줄 간격과 중첩 목록을 확인해 주세요.
3. **Google Docs, Word, Gmail에 서식 복사를 붙여넣은 결과.**
4. **한글 입력기(IME)로 직접 타이핑.** 자동 테스트는 글자를 직접 주입하는 방식이라, 자음과 모음이 조합되는 과정은 확인하지 못했습니다.

## Swift 순수 앱 (새 버전, `macos/`)

브라우저 엔진 없이 맥 기본 부품(AppKit)으로 다시 만든 버전입니다. 기능은 위의 맥 앱과 같고, 훨씬 가볍습니다. 계획과 기준은 [docs/SWIFT_PLAN.md](docs/SWIFT_PLAN.md)에 있습니다.

| 항목 | Electron 버전 | Swift 버전 (실측) |
|---|---|---|
| 앱 크기 | 310MB | 6.4MB (Apple Silicon·Intel 공용) |
| 메모리 (예제 문서 1개, 분할 보기) | 150~300MB (추정) | 45MB (`footprint` 명령, 최고 45.7MB) |

**만들기와 설치**
1. Xcode가 설치되어 있어야 합니다. 저장소 폴더에서 `bash macos/scripts/build-app.sh`를 실행합니다.
2. `macos/build/MD Studio.app`이 생깁니다. 응용 프로그램 폴더로 옮기면 됩니다. 이 맥에서 직접 만든 앱이라 "확인되지 않은 개발자" 경고가 뜨지 않습니다. 다른 맥으로 보낼 때는 `macos/build/MD-Studio-2.0.0-mac.zip`을 쓰고, 받는 쪽은 위의 "그래도 열기" 순서를 따릅니다.
3. Electron 버전과 따로 설치됩니다(앱 식별자 `local.mdstudio.native`). 설정과 임시본도 따로 보관합니다.

**자동 확인**: `bash macos/scripts/build-app.sh --selftest`를 실행하면 앱을 만든 뒤 실제 창을 띄워 25개 흐름(폴더 열기, 저장, 자동 저장, 임시본 복구, 외부 변경, 복사 4종, 붙여넣기 변환, HTML·PDF 내보내기, 단축키, 다크 모드, 긴 문서, 분할 경계 끌기 등)을 사람 없이 실행합니다. 결과와 화면 사진은 `macos/build/selftest/`에 남습니다. 점검하는 동안 앱 창이 30초쯤 떴다가 닫힙니다.

**Electron 버전과 다른 점**
- 미리보기는 브라우저가 아니라 맥 글자 엔진으로 그립니다. 디자인은 같은 색과 크기를 쓰지만 줄 간격 등은 조금 다를 수 있습니다.
- 인터넷 주소의 이미지는 미리보기에서 내려받지 않고 "[이미지: 설명]" 링크로 보여 줍니다(내 맥의 이미지 파일은 그림으로 보입니다).
- 마크다운 안에 직접 쓴 HTML 태그는 서식 복사·보고서에서 글자만 남깁니다(웹 버전은 일부 태그를 살렸습니다).
- 서식 복사에 RTF도 함께 넣어 Pages·Word 붙여넣기가 더 잘 됩니다.
- "서식" 메뉴가 추가되었고, 보고서 미리보기는 기본 브라우저로 엽니다.
- 편집기와 미리보기 사이 경계를 마우스로 끌어 폭을 바꿀 수 있습니다. 바꾼 비율은 기억되고, 경계를 두 번 누르면 반반으로 돌아갑니다. 칸이 좁아지면 서식 버튼은 뒤에서부터 숨고(서식 메뉴·단축키로는 계속 쓸 수 있음) 미리보기 탭 이름은 짧아집니다.
- 로그는 `~/Library/Logs/MD Studio/app.log`에 남습니다.

## 개발자용

```
npm install        # 의존성 설치
npx playwright install chromium-headless-shell  # 화면 테스트용 브라우저 (처음 한 번)
npm run build      # dist/MD-Studio.html 생성
npm test           # 변환 로직 단위 테스트
npm run e2e        # 실제 브라우저 테스트 (Playwright, 스크린샷은 test/screenshots/)
npm run app        # 데스크톱 앱으로 실행 (개발용)
npm run e2e:app    # 데스크톱 앱 테스트 (맥은 앱 창이 잠깐 떴다 닫힘, Linux는 xvfb 필요)
npm run package:app  # 맥 앱 생성 → release/MD-Studio-<버전>-mac-*.zip (서명·검증까지 자동)
node test/make-golden.mjs  # 변환 정답 데이터 갱신 (다른 언어 구현과 대조용)
cd macos/MDCore && swift test  # Swift 변환 엔진을 정답 데이터와 대조 (Xcode 필요)
cd macos/MDStudio && swift test  # Swift 앱 기능 단위 테스트
bash macos/scripts/build-app.sh --selftest  # Swift 앱 만들기 + 실제 창 자동 점검
```

구조:
- `src/convert.js`: 마크다운을 Slack용 HTML, 플레인 텍스트, 문서용 HTML로 바꾸는 핵심 로직입니다. 표를 목록으로 푸는 규칙도 여기 있습니다. 브라우저 기능 없이 동작하므로 Node에서 바로 테스트할 수 있습니다.
- `src/output.js`: 서식 복사용 인라인 스타일, 클립보드 쓰기, HTML 보고서, 붙여넣기 변환(HTML을 마크다운으로)을 담당합니다.
- `src/editor.js`: CodeMirror 편집기 설정과 서식 명령입니다.
- `src/storage.js`: 폴더와 파일 저장(File System Access API), 임시본, 설정 저장입니다.
- `src/logger.js`: 로그 기록입니다.
- `src/main.js`: 화면과 각 모듈을 연결합니다.
- `build.mjs`: 모든 코드와 스타일을 HTML 파일 하나로 묶습니다.
- `electron/main.cjs`: 데스크톱 앱의 메인 프로그램입니다. 파일·폴더·클립보드·PDF·메뉴를 담당하고, 사용자가 고른 경로 밖은 거부합니다.
- `electron/preload.cjs`: 화면이 쓸 수 있는 앱 기능 목록입니다(`window.mdNative`).
- `macos/MDStudio/`: Swift 맥 앱입니다. `MDStudioKit`(화면·파일·클립보드·PDF 등 모든 기능)과 실행 파일 `MDStudio`로 나뉩니다. `macos/scripts/build-app.sh`가 `.app`으로 묶고 자체 서명합니다.
- `macos/MDCore/`: Swift 버전의 변환 엔진(Swift Package)입니다. `src/convert.js`와 같은 결과를 내며, `swift test`로 `test/fixtures/golden.json`과 대조합니다.
- `mac/`: 앱 아이콘(`icon.svg`, `AppIcon.icns`)과 자체 서명·압축 스크립트(`adhoc-sign.sh`)입니다.
